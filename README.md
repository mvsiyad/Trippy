# Trippy 🧭

An interactive travel discovery guide and trip cost estimator for iconic destinations across India and worldwide.

## Features
- **Destination Guides**: Curated profiles with season intel, highlights, regional food, and route logistics.
- **Season Radar**: Month-by-month recommendations to find ideal travel windows.
- **Trip Cost Estimator**: Dynamic daily cost breakdowns (lodging, transit, food, activities) across backpacker, mid-range, and luxury tiers.
- **Traveler Hacks**: Field advice on altitude acclimatization, currency exchange, mountain buses, and offline navigation.
- **Bucket List**: Save your preferred destinations with persistent local storage.

## Tech Stack
- HTML5 (Semantic & Accessible)
- CSS3 (Vanilla design system, CSS variables, Glassmorphism, Responsive Grid/Flexbox)
- JavaScript (ES6+ client-side logic)
- Font Awesome 6
- Google Fonts (Outfit, Plus Jakarta Sans, JetBrains Mono)

## Getting Started
Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/mvsiyad/Trippy.git
cd Trippy
```

Open `index.html` directly or serve using any static web server.
